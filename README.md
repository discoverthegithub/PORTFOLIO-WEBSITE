# 🚀 Muhammad Tayyab's Portfolio

Welcome to my personal portfolio repository! This is a modern, responsive, and highly interactive web application designed to showcase my skills, projects, achievements, and professional journey as a Full Stack Developer and AI/ML Enthusiast.

## ✨ Key Features

-   **Modern Glassmorphism UI:** Built with sleek, native-feeling translucent effects, soft gradients, and polished drop-shadows.
-   **Advanced Animations:** Smooth transitions and floating interactions powered by CSS and Framer Motion.
-   **Tailored Chatbot (AI Powered):** An integrated Gemini AI agent fine-tuned using custom JSON data to answer any questions about my skills and background as my personal assistant!
-   **Fully Responsive:** Perfect viewing experience across desktop, tablet, and mobile devices.
-   **Dark/Light Mode Support:** Dynamically shifts styling logic, ensuring perfect accessibility in any lighting condition.
-   **Interactive Sections:** 
    -   *Hero Area* with glowing profile badge animations.
    -   *Experience & Education* cards with lifting hover interactions.
    -   *Projects Gallery* with immersive image scaling.
    -   *Animated Social Links* with brand-specific expanding colors on hover.
-   **Clean Code Architecture:** Modular React components meticulously organized for reusability and scalability.

## 🛠️ Tech Stack

-   **Frontend:** React.js, Vite
-   **Styling:** Vanilla CSS (Advanced properties, variables, and animations)
-   **Animations:** Framer Motion, Native CSS Keyframes
-   **AI Integration:** Google Gemini API (`gemini-2.5-flash`)
-   **Icons:** React Icons
-   **Routing:** React Router DOM

## 📥 Local Development Setup

To run this project locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/your-portfolio-repo.git
    cd your-portfolio-repo
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Set up Environment Variables:**
    Create a `.env` file in the root directory and add your Google Gemini API key:
    ```env
    VITE_GEMINI_API_KEY=your_gemini_api_key_here
    ```

4.  **Start the development server:**
    ```bash
    npm run dev
    ```
    The site will start running on your `localhost`. 

## 🌐 Deployment 

This site is perfectly optimized for swift deployment on platforms like Netlify or Vercel using the standard `npm run build` command. **Note:** Remember to manually add your `VITE_GEMINI_API_KEY` into the environment variable settings of your hosting provider!
